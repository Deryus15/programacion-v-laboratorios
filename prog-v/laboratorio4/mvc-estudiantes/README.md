# MVC Estudiantes

Proyecto didáctico para enseñar MVC con:

- Java 21
- Spring Boot 4.1.1
- Spring MVC
- Spring Data JPA
- Thymeleaf
- Bootstrap
- MariaDB
- Maven

## Inicio rápido

1. Ejecutar `database.sql`.
2. Revisar usuario/contraseña en `src/main/resources/application.properties`.
3. Importar como proyecto Maven en Eclipse.
4. Ejecutar `MvcEstudiantesApplication.java`.
5. Abrir `http://localhost:8080`.

Lea `GUIA_PRACTICA.md` para la práctica completa.
